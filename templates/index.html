HOW IT WORKS

🎯

YOU MAKE A CHOICE

You answer hypothetical everyday scenarios.

💾

WE SAVE THE PATTERN

Your choices and their behavioural tags are recorded.

🔮

THE MACHINE MAKES A GUESS

The Python engine scores each option from your history.

😈

YOU PROVE IT WRONG. OR NOT.

The guess is checked against your real answer.

The prototype uses frequency counts, category-specific history, and weighted scoring. It is a simple educational prediction model, not a scientific psychological assessment.

THE NERDY DETAILS
  • Choice frequencies: every answer is stored in SQLite; the engine counts how often you picked each behaviour key inside each scenario category.
  • Tags: each option carries internal tags (like cautious or social). Picking it adds 1 to each tag counter.
  • Scoring: score = 0.65 × category history + 0.35 × tag score, both scaled 0 to 1. Highest wins; ties go to the first option.
  • Accuracy: correct ÷ predictions actually made × 100. Rounds with no guess are not counted.
  • Why it improves: more stored answers means counters reflect your habits, not noise. The "confidence" shown is a heuristic, not a calibrated probability.

A TINY EXPERIMENT ABOUT THE CHOICES WE MAKE.

Brain Rot Lab is an interactive Python project exploring a simple question: can a program use previous choices to make better guesses about what someone might choose next?

It collects answers to hypothetical scenarios, tracks recurring patterns, and uses a lightweight prediction algorithm to evaluate its guesses.

The goal is to make basic data analysis, probability, and predictive logic understandable through an entertaining game. Built with Python, Flask, SQLite, HTML, CSS and JavaScript. No advanced machine learning involved.
